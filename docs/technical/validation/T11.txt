7 passed on the full local application stack.
- The owning teacher uses the UI to remove and readmit the same student,
  and archives and restores the class. Removal retains the original joined
  timestamp. Restoration keeps the composite membership identity and advances
  its version. Repeated removal or archival does not add an audit event.
- A different teacher gets 404 on the owner-scoped mutations. Students get
  403 on teacher mutations, including attempted self-removal.
- Archived classes are absent from active lists. In the archived list, roster
  history and pending names are visible. The owner can restore the class.
  Edit, approve, issue-one, remove, and readmit return 409 while archived.
  Join by code fails and CSV flags the row, with no enrollment created.
- Suspension through the admin API revokes the teacher's access to the roster
  and every tested mutation. The other teacher can still edit their class.
  The shared student's second membership retains the same state and version.
