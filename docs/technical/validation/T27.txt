- A teacher uses the rich Markdown editor to add a document containing an
  authorized image and a normal external hyperlink. A new item is private.
  The teacher can share with both owned classes. Another teacher's class
  is rejected, and the API rejects whole external-link items.
- The application reads UTF-8 TXT and returns its exact downloaded bytes.
  It serves a valid PDF fixture to the embedded reader and downloads the
  exact bytes. An HTML file claiming to be PDF is rejected. The provider
  stores Markdown manifests, PDF/TXT blobs and the managed image with
  private file permissions. The DB holds object and ACL metadata.
- An unshared class cannot access the reader, download or image lease by
  direct URL. After sharing, both classes have access. A lease is bound
  to its application session. The favorite filter only includes favorites
  that still pass the current ACL. Removal from a class and revocation of
  its share block the reader and download and invalidate previously issued
  image leases. The saved favorite remains metadata after access is lost.
