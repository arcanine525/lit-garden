The browser test builds a two-point rubric with all five criteria and 13
scoring levels. The operator opens the editing form, creates a revision, and
retires it through the UI. The teacher and student open the current rubric.
The teacher opens all five criteria and reads every description. Direct create,
revise, and retire requests from both read-only roles return 403. Cross-origin
mutation returns 403. Duplicate scores for a criterion return 422.

The previously stored definition stays unchanged. Revision edits with a stale
expected version return 409. Retrying identical create, revise, or retire
requests inserts no extra revision or audit event. The database rejects edits
to an older definition or reactivation of a retired revision. Retirement hides
the entire rubric from the teacher and student catalog, even though the admin
can select and read previous versions. The audit contains one event per action.

The rubric fixture is created and removed by the browser test. Production
rubrics are entered by the operator. The catalog exposes only the current
active revision for new assignments. Assignment pages and immutable Drive
snapshots are part of T17. No live Google service was used.
