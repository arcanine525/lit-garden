## Đối chiếu rubric theo viewport

Dùng bộ 0 “Đoạn nghị luận xã hội”, thang 2 điểm, năm tiêu chí đóng và thứ tự từ dữ liệu khảo sát. E2E so từng tiêu chí với DOM nguồn đã chụp. Điều kiện tái dùng ảnh gốc là nội dung, trạng thái và shell khớp tại chính viewport cần so. Mỗi shell đích hiện có điều khiển Thông báo ở topbar, điều khiển này vắng trong cả sáu ảnh nguồn. Vì vậy bộ đề xuất dùng mockup cho cả sáu tổ hợp sau.

Ảnh gốc của các trạng thái còn lại tiếp tục là tư liệu khảo sát. Mockup mới được chọn khi thay đổi hành vi hoặc shell. Các cảnh chỉ có ở demo và các điều khiển AI, DOCX, thêm liên kết ngoài hoặc trải nghiệm công khai được loại khỏi đích theo F17/F23/F34/F40. Cả hai bộ ảnh được lưu riêng để truy lại nguồn.

## Mở lại bộ ảnh

Chạy `npm --prefix prototypes/editor run dev` và mở <http://127.0.0.1:4311/baselines/>. Query `?scene=<ID>` mở đúng fixture. Chạy `CAPTURE_BASELINES=1 npm --prefix prototypes/editor run test:browser -- baselines.spec.js` để tái tạo cả ma trận. Để chỉ ghi lại vài cảnh, đặt `CAPTURE_BASELINES` bằng danh sách ID phân cách bằng dấu phẩy. Chạy bộ E2E chỉ đọc bằng `npm --prefix prototypes/editor run test:browser`.
